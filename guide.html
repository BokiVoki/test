이 시스템은 무엇인가요?

그래픽 도서 관리 시스템은 이태원점·위례점 두 지점의 도서를 웹 브라우저 하나로 통합 관리하는 전용 시스템입니다. 별도 프로그램 설치 없이 어디서든 접속해 재고 확인, 입출고 기록, 위치 관리까지 모두 처리할 수 있습니다.

두 지점 통합이태원·위례 재고를 한 화면에서 관리
웹 기반설치 불필요, 브라우저로 바로 접속

도서 관리 — 재고관리 탭

관리자 페이지의 핵심 탭입니다. 스프레드시트처럼 생긴 화면에서 도서 데이터를 직접 수정합니다.

탭 이름역할주요 컬럼
전체 DB모든 도서의 마스터 정보ISBN, 제목, 출판사, 작가, 이태원 재고, 위례 재고, 태그, 한줄평, 위치, 표지 URL, 절판 여부 등

💡 재고 자동 조정: '처리' 체크박스를 체크하면 재고가 자동으로 증감합니다. 발주→입고 시 자동 증가, 판매 체크 시 자동 감소. 1회만 적용되고 중복 처리되지 않습니다.

위치 관리 기능

도서 위치 탭 (이태원·위례 공통)

  • 알파벳 그룹 → 섹션 → 도서 순서의 3단계 계층 구조
  • 위치 형식: 섹션명 + 행번호 + -열번호 (예: A2-3, 지하A1-2)
  • 드래그 앤 드롭으로 도서 순서 변경
  • 자연 정렬(Natural Sort) 적용

층별 안내도 탭 (이태원점)

  • 섹션별 행×열 그리드로 도서 배치를 시각적으로 관리
  • 도서를 드래그 앤 드롭으로 셀 간 이동
  • 빈 공간 드래그로 여러 도서 동시 선택 후 일괄 이동
  • 미배치 도서는 '바구니/미지정' 패널에서 관리
  • 셀 너비를 개별 조절해 DB에 저장 — 모든 관리자가 동일한 레이아웃 공유
  • 가안(Draft) 시스템: 최대 5개 레이아웃 안을 서버에 저장·공유
  • 도서 제목 검색 후 클릭하면 해당 위치로 자동 스크롤
